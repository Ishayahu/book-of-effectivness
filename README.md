# Book of Effectivness

Рабочий репозиторий книги об эффективности человека в еврейской системе координат.

Это **не Zettelkasten**. Основной материал здесь должен развиваться как связный текст: главы, разделы, аргументация, источники, оговорки и переходы между идеями.

## Текущая структура

- `manuscript/00-overview.md` — карта замысла и методологические оговорки.
- `manuscript/01-middah-as-resource.md` — первая связная глава: от исследования ушпизин к модели миды как ресурса и многоуровневой эффективности.
- `manuscript/02-keep-course-without-guarantees.md` — вторая связная глава: условность контроля и ресурсов, стартовые условия, адаптация и сохранение курса.
- `manuscript/03-what-a-person-possesses.md` — третья связная глава: обладание, передача ценности, распределённый след, диверсификация и связь правильного поступка с вечностью.
- `research/next-questions.md` — вопросы, которые требуют отдельной проверки источников.

Рабочее название книги пока: **«Эффективность человека»**.
